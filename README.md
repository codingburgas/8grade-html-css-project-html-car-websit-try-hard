# 8grade---RentACar

**First 8th grade project – Car Rental Website**

##  Project Description

This website was created as part of a project assignment in HTML & CSS for 8th-grade students at the Vocational High School of Computer Programming and Innovations in Burgas, Bulgaria. The goal of the project is to make a good website and get good grades.

##  Technologies Used

**WindowsFileExplorer** – to make the folders with the files
- **VSC** – we used it instad of notepad  
- **CSS** – for styling and layout  
- **HTML** – for the structure of the site

##  Website Structure

- Homepage  
- Navigation menu categories: 
- Pages with detailed information for each category  
- Contact form for user inquiries
